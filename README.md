# Мой лаунчер для Sony Android TV

Лёгкий главный экран для Sony KD-49XD7005 (и других Android TV с Android 5–14):

- **часы и дата** сверху;
- **«Избранное»**: первой стоит **TV+ Казахтелеком**, за ней **Google Play** и **YouTube**, в конце «Настройки ТВ»;
- **«Все приложения»**: всё установленное, по алфавиту. Новые приложения из Google Play появляются сами.

Он быстрый, потому что в нём ничего лишнего: нет рекламных рядов, рекомендаций, превью видео, фоновых обоев и сторонних библиотек. APK весит меньше 100 КБ.

## Пульт

| Кнопка | Что делает |
| --- | --- |
| Стрелки, OK | выбрать и открыть |
| Долгое нажатие OK или ☰ | добавить в «Избранное» или убрать оттуда |
| ◀◀ / ▶▶ на плитке в «Избранном» | передвинуть плитку влево / вправо |
| PROG + / − или цифры | сразу включить «Телевизор» |
| Home, Назад | вернуться к первой плитке |

Каналы TV+ переключаются внутри самого приложения TV+, как обычно. Лаунчер открывает TV+ одним нажатием, но выбрать в нём канал снаружи не может: приложение Казахтелекома этого не позволяет.

## Шаг 1. Собрать APK (бесплатно, через GitHub)

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Нажмите **New repository**, придумайте имя (например `tv-launcher`), выберите **Private** и нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**. Перетащите туда **всё содержимое** распакованной папки `tv-launcher`, включая папки `.github`, `gradle` и `app`. Затем нажмите **Commit changes**.
   > Папка `.github` скрытая. В Windows включите «Вид → Скрытые элементы», иначе она не загрузится и сборка не запустится.
4. Откройте вкладку **Actions**. Сборка «Собрать APK» запустится сама и займёт 3–5 минут.
5. Когда появится зелёная галочка, откройте сборку и внизу в **Artifacts** скачайте `tv-launcher-apk`. Внутри zip лежит файл `app-release.apk`.

Если сборка завершилась красным крестиком, пришлите текст ошибки, я исправлю.

## Шаг 2. Установить на телевизор

1. На ТВ: **Настройки → Безопасность и ограничения → Неизвестные источники**, разрешите установку.
2. Перенесите APK на телевизор одним из способов:
   - **флешкой**: скопируйте `app-release.apk` на флешку и вставьте её в ТВ;
   - **без флешки**: поставьте приложение **Send Files to TV** из Google Play на телефон и на ТВ, затем отправьте файл с телефона.
3. Откройте APK файловым менеджером на ТВ (например, **File Commander** или **X-plore** из Google Play) и нажмите **Установить**.

## Шаг 3. Сделать главным экраном

Нажмите **Home** на пульте. Если ТВ спросит, какое приложение использовать, выберите **«Мой лаунчер» → «Всегда»**.

Если вопрос не появился, открывайте лаунчер из списка приложений, а кнопку Home можно перенастроить через компьютер (ADB). Я помогу с этим отдельно.

## Обновления

Новые версии ставятся **поверх старой, без удаления**, и избранное сохраняется. Это работает благодаря постоянному ключу подписи `app/launcher.keystore`.

**Не удаляйте и не теряйте этот файл.** Если он пропадёт, новую версию придётся ставить только после удаления старой.

## Для разработчика

- Весь код в одном файле: `app/src/main/java/kz/home/tvlauncher/MainActivity.java`.
- Список «Избранного» по умолчанию задаётся в массиве `DEFAULT_FAVORITES`.
- Цвета: `app/src/main/res/values/values.xml`.
- Локальная сборка: Android Studio → Open → эта папка → Build → Build APK(s). Или в терминале: `./gradlew assembleRelease`.
